# Security policy

If you believe you found a security issue in CoordKit, please report it
privately to the maintainers before disclosing it publicly.

Preferred contact:

- codehornets@gmail.com

Please include:

- a short description of the issue;
- the affected files or commands;
- the steps needed to reproduce it;
- any risk or impact you observed.

Do not include secrets, tokens, or live credentials in the report.

CoordKit currently ships a relay and host-integration hooks, so anything that
affects authentication, repository writes, or cross-machine event delivery is
considered security-sensitive.
